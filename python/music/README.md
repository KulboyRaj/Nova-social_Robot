# music/

Drop a few royalty-free `.mp3` files here for the local-playback fallback
used by `actions/music.py` when Spotify isn't configured (the default,
demo-safe `NOVA_MUSIC_METHOD=local`).

Good royalty-free sources: YouTube Audio Library, Free Music Archive, or
Pixabay Music. Nothing is included in this repo by default so no
copyrighted audio gets committed to your GitHub repo.
